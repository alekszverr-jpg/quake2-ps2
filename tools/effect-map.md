# Flowing-surface test room

Select **Game -> test map -> ps2flow - flowing surface test**, then load the
map. Console alternative: `map ps2flow`. Alpha.91 adds the menu entry.

The spawn faces three labelled panels:

| Label | Expected behaviour |
| --- | --- |
| STATIC (left) | Vertical stripes stay still. |
| OPAQUE (centre) | Same stripes scroll horizontally; surface is opaque. |
| GLASS (right) | Stripes scroll; stationary grid behind remains visible. |
| DOOR (right wall) | Approach the striped shield to move it along the wall; texture keeps scrolling while the inline brush moves and returns. |

Observe the centre and right samples from different angles and close to the
camera. Watch for cracks, sudden texture-coordinate jumps, or differences
between clipped and unclipped triangles. Shoot the opaque sample with the
blaster to also exercise dynamic-light subdivision with scrolling coordinates.
The room contains no monsters and no water/SURF_WARP surfaces.

The geometry and six indexed WAL textures are original procedural assets
generated by [effect_map.py](effect_map.py), under the repository's GPL v2
licence. No commercial game assets are included. Compilation uses
[yquake2/maptools](https://github.com/yquake2/maptools) at commit
`9b7e43334646f63f25a7aebfd62070b3aebc2554`, derived from the GPL Quake II tools.
`prepare_maptools.py` fixes QRAD's pointer alignment cast from `int` to
`uintptr_t`: the original truncates the address and crashes on a 64-bit host.
CI runs QBSP, QVIS and QRAD, then checks BSP38 structure, actual face flags,
visibility, lightmaps, player hull spawn clearance and the inline door model.

To rebuild on Linux, generate into a directory containing the exact path
`quake2/baseq2` (required by the compiler's game-directory inference):

```sh
python3 tools/effect_map.py build/effect-map/quake2/baseq2
python3 tools/prepare_maptools.py build/effect-map-tools
make -C build/effect-map-tools -j2 release/qbsp3 release/qvis3 release/qrad3 CFLAGS="-O2 -fcommon -fno-strict-aliasing -Wall -MMD"
build/effect-map-tools/release/qbsp3 -leaktest "$PWD/build/effect-map/quake2/baseq2/maps/ps2flow.map"
build/effect-map-tools/release/qvis3 "$PWD/build/effect-map/quake2/baseq2/maps/ps2flow.bsp"
build/effect-map-tools/release/qrad3 -threads 1 -bounce 0 -ambient 0.2 "$PWD/build/effect-map/quake2/baseq2/maps/ps2flow.bsp"
python3 tools/effect_map.py build/effect-map/quake2/baseq2 --verify
```

Download the CI `ps2flow-test-map` artifact. Copy its `maps/ps2flow.bsp` and
`textures/ps2test/*.wal` into the matching directories inside `baseq2`.
The `.map` source is optional at runtime. **Do not install the generated
compiler-only `pics/colormap.pcx`**: runtime must retain the game's palette.
The artifact intentionally excludes it. Other maps and PAK files are unchanged.
